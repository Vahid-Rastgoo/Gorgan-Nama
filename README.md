# گرگان‌نما: راهنمای مغازه‌ها و خدمات گرگان (اندروید)

اپ بومی با Kotlin و Jetpack Compose، کاملاً فارسی و راست‌به‌چپ. یک برنامه با دو کاربرد:

* **برای مردم:** پیدا کردن مغازه و خدمات گرگان
* **برای تو:** فروش اشتراک، ثبت ویزیت‌های میدانی، پیگیری تمدید و انتشار کاتالوگ

## امکانات

**بخش عمومی**
- خانه: جستجو، ۱۵ دسته‌بندی، ویترین ویژه، تخفیف‌ها، تازه‌ها، دکمه «کسب‌وکارم را ثبت کن»
- جستجوی فارسی هوشمند (ی/ک عربی، نیم‌فاصله، ارقام فارسی) با فیلتر دسته، محله، «الان باز»، تخفیف‌دار، ویژه و تأییدشده؛ سه حالت مرتب‌سازی
- صفحه مغازه: تماس، مسیریابی (نشان، بلد، گوگل‌مپ)، معرفی به دوستان، اینستاگرام، ایتا، روبیکا، سایت، ساعت کاری و وضعیت باز/بسته زنده، روزهای تعطیل، تخفیف، برچسب‌ها، گزارش اشتباه
- نشان‌شده‌ها (علاقه‌مندی‌ها)، صفحه تخفیف‌ها، تاریخ شمسی، حالت تیره

**پنل مدیریت (با رمز؛ پیش‌فرض ۱۲۳۴)**
- داشبورد: درآمد این ماه و کل، اشتراک‌های فعال، تمدیدهای ۳۰ روز آینده، منقضی‌ها، بدهکارها، پیشرفت ویزیت روزانه (هدف ۲۰)، نرخ تبدیل ۳۰ روز
- مغازه‌ها: افزودن و ویرایش با همه فیلدها، عکس از گالری یا لینک، مختصات از لینک گوگل‌مپ، پیش‌تنظیم ساعت کاری، پلن رایگان/پایه/ویژه، ثبت پرداخت و فعال‌سازی یا تمدید یک‌ساله، سابقه پرداخت، یادداشت خصوصی
- ویزیت‌ها (فروش میدانی): ثبت سریع با «ذخیره و مغازه بعدی»، وضعیت (علاقه‌مند، پیگیری، نبود، مشتری شد، نخواست)، تاریخ پیگیری، تبدیل به مشتری با یک ضربه
- یادآوری تمدید با پیامک آماده و تماس
- تنظیمات: قیمت پلن‌ها، هدف روزانه، شماره پشتیبانی، لینک کاتالوگ، تغییر رمز، خروجی کاتالوگ عمومی، پشتیبان کامل، بازیابی، حذف نمونه‌ها، مخفی کردن تب مدیریت (ورود با ۵ ضربه روی عنوان)

## گرفتن APK

### راه ۱ (پیشنهادی): ساخت خودکار در GitHub
1. یک ریپازیتوری جدید در GitHub بساز و همه فایل‌های این پوشه را آپلود کن.
2. تب **Actions** را باز کن؛ ساخت «Build APK» خودکار شروع می‌شود (یا دستی Run workflow بزن).
3. بعد از چند دقیقه، از پایین صفحه همان اجرا فایل **GorganNama-apk** را دانلود کن؛ داخلش `app-debug.apk` است.

### راه ۲: Android Studio
1. Android Studio را نصب کن و پوشه پروژه را با **Open** باز کن.
2. صبر کن Gradle همگام شود، بعد: **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
3. فایل در `app/build/outputs/apk/debug/` ساخته می‌شود.

> اگر دانلودهای Gradle یا Google با خطای 403 متوقف شد، این محدودیت سرورهای گوگل برای ایران است. از DNS ضدتحریم استفاده کن یا راه ۱ را برو.

APK دیباگ برای نصب روی گوشی خودت و دیگران کافی است. برای بازار و مایکت از **Build > Generate Signed App Bundle / APK** نسخه امضاشده بگیر و فایل کلید را جای امن نگه دار.

## انتشار برای مردم (بدون سرور)
1. روی گوشی خودت مغازه‌ها را ثبت کن.
2. تنظیمات پنل > **خروجی کاتالوگ عمومی** (پرداخت‌ها و یادداشت‌ها داخلش نیست).
3. فایل را جایی با لینک مستقیم https آپلود کن (مثل GitHub یا فضای ابری).
4. در `app/src/main/java/com/vahid/gorgannama/Config.kt`:
   - `PUBLIC_BUILD = true`
   - `DEFAULT_CATALOG_URL = "لینک فایل"`
   - `ADMIN_PHONE = "شماره تو"`
5. APK بگیر و پخش کن. هر بار کاتالوگ را دوباره آپلود کنی، گوشی‌ها حداکثر هر ۶ ساعت به‌روز می‌شوند.

اختیاری: فایل کاتالوگ را جای `app/src/main/assets/catalog.json` بگذار تا اولین اجرا بدون اینترنت هم پر باشد.

## محدودیت‌های نسخه ۱ (صادقانه)
- سرور ندارد؛ آمار بازدید و تماس هر مغازه، نظرات کاربران و ثبت‌نام آنلاین خود مغازه‌دار به بک‌اند نیاز دارد. برای اینکه بابت «دیده شدن» پول بگیری، آمار بازدید مهم‌ترین قدم بعدی است.
- عکس‌هایی که از گالری انتخاب می‌شوند فقط روی گوشی تو هستند؛ برای نسخه عمومی لینک عکس بگذار.
- ۱۰ مغازه داخل برنامه **نمونه و ساختگی** هستند (اسمشان «نمونه» دارد) و از تنظیمات یک‌جا حذف می‌شوند.

## ساختار کد
```
app/src/main/java/com/vahid/gorgannama/
  Config.kt            تنظیمات نسخه عمومی/شخصی
  MainActivity.kt
  data/                مدل‌ها، دسته‌ها، JSON، Store (ذخیره و همگام‌سازی)
  util/Util.kt         تاریخ شمسی، ارقام فارسی، ساعت کاری، مختصات، فایل
  ui/                  تم، ناوبری، خانه، جستجو، تخفیف‌ها، جزئیات، پنل مدیریت، فرم‌ها
```
مشخصات فنی: minSdk 26 (اندروید ۸ به بالا)، targetSdk 34، Kotlin 1.9.24، AGP 8.5.2، Gradle 8.7، JDK 17.
